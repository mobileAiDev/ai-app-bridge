For App/device work, use AI App Bridge by default, including ADB through `adb-exec`. Use Intent for observation-driven decisions and Script for code-driven tasks, including one-off work. Standalone logs, screenshots, queries and atomic actions can call their Bridge command directly.

Use another tool for an explicit user choice or a confirmed Bridge availability/capability gap; a failed SDK command does not rule out UIA/ADB. Read the `ai-app-bridge-use` skill for this work; query `capabilities` by command/operation when arguments are unknown.
