## 2026-09-10 用户纠偏后的当前优先级

用户明确指出：冷重启、损坏、淘汰和容量边界是基础能力，核心目标是操作、验证各种复杂 App，并证明 Intent 与 Script 的实际能力。此前把基础专项全部收口排在复杂 App 与 iOS 执行入口之前，推进顺序偏离了目标。本节覆盖此前的串行门禁顺序；基础合同和未完成项仍保留，不能把延期写成通过。

当前主线是 **复杂 App 的真实业务任务 → Intent 操作与本轮证据 → Agent 编写 Script → 同一业务任务复跑和独立结果核验 → 扩展到不同 App 与平台 → 组合整机回归**。每轮须说明新增或修复了哪项业务操作、脚本复用或错误识别能力。只有阻断当前具名业务流程、导致误操作或错误结论的基础缺陷，才立即插入主线修复；修复完成后回到该业务流程。
